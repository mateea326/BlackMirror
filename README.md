# Black Mirror Universe

An interactive fan-made web application dedicated to the TV show *Black Mirror*.

## Key Features

- **Interactive Maze Game**: custom-built 2D game with multiple levels
- **Knowledge Quiz**: interactive quiz 
- **Episode Directory**: guides and insights for popular episodes like *The Entire History of You*, *Nosedive*, and *Bandersnatch*

## Technical Overview

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
